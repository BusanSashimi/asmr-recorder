Removed the 11-line static `import { Input, Output, BlobSource, ... } from "mediabunny"`.  
Replaced with:
- `import type { Input, EncodedPacketSink, EncodedPacket }` at the top (type-only, erased at build time — no runtime chunk in main bundle)
