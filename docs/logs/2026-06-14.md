### Native screen transport: raw bytes + ack-based backpressure (`native-screen-transport-raw-bytes.md`)

**Backend (`src-tauri/src/screen_stream.rs`):**

- Deleted `ScreenStreamFrame` struct (was `data: String, width, height, timestamp_ms` — base64 JPEG payload).
- Added `parking_lot::{Condvar, Mutex}` + `tauri::ipc::{Channel, InvokeResponseBody}` imports.
- Added `MAX_INFLIGHT: u32 = 2` constant (ack-based backpressure credit ceiling).
- `StreamHandle` extended with `credit: Arc<(Mutex<u32>, Condvar)>`.
- Worker encodes JPEG as before, then:
  1. Builds 16-byte LE header: `u32 width | u32 height | u64 timestamp_ms`, prepends it to the JPEG payload.
  2. Blocks on `Condvar::wait_for` (timeout = `RECV_TIMEOUT = 100 ms`) until credit > 0, then decrements credit.
  3. Sends via `on_frame.send(InvokeResponseBody::Raw(payload))`.
- `on_frame` param type changed from `Channel<ScreenStreamFrame>` to `Channel<InvokeResponseBody>`.
- New `ack_screen_frame(section_index, state)` command: finds the handle, increments credit, notifies the Condvar.
- `lib.rs`: `screen_stream::ack_screen_frame` registered in `generate_handler!`.

**Frontend (`frontend/src/`):**

- **`lib/native-screen.ts`** — `ScreenStreamFrame.data: string` field removed (only `width, height, timestampMs` remain). `startNativeScreenStream` return type `Channel<ScreenStreamFrame>` → `Channel<ArrayBuffer>`. `channel.onmessage` now: parses the 16-byte LE header with `DataView.getUint32` / `getBigUint64`; wraps the tail slice in a `Blob({ type: "image/jpeg" })`; resolves `createImageBitmap(jpeg)` then calls `onFrame` + `ack()`; always calls `ack()` on decode failure too.
- **`components/asmr-recorder/preview.tsx`** — `nativeScreenChannels` ref type `Channel<ScreenStreamFrame>` → `Channel<ArrayBuffer>`; removed unused `type ScreenStreamFrame` import; removed 30fps cap (`Math.min(..., 30)` → uncapped `externalConfig.frameRate || 30`).

### Trim editor v2 — multi-segment cuts, frame-accurate option, thumbnail filmstrip (`trim-editor-v2-multisegment.md`)

All changes in `frontend/src/components/asmr-recorder/trim-editor.tsx`.

**New type:**
- `Segment = { in: number; out: number }` — a keep-range in seconds.

**`trimToBuffer` generalized:**
- Signature: `trimToBuffer(input, segments: Segment[], frameAccurate: boolean)`.
- Loops over segments; per segment: finds startKey + audioStart, computes `origin = min(startKey.ts, audioStart.ts)`, saves `segOffset = timelineOffset` (fixed for the segment so A/V both use the same base), packet-copies video then audio rebasing with `p.timestamp - origin + segOffset`, updates `timelineOffset = lastVideoEnd` after each segment.
- `firstVideo`/`firstAudio` booleans span all segments so only the first-ever packet carries `decoderConfig`.
- Skips segments shorter than 50ms.

**Frame-accurate leading GOP re-encode:**
- `reencodeLeadingGop(mb, videoTrack, inSec, gopEnd)`: creates a mini-output with `VideoSampleSource` (config has `onEncodedPacket` to collect packets), decodes `[inSec, gopEnd)` via `VideoSampleSink.samples()`, calls `sample.close()` after each add, returns `EncodedPacket[]` with timestamps in clip-seconds.
- Guard: `await canEncodeVideo(...)` — if false, falls back to lossless with a toast.
- Main output uses `p.timestamp - seg.in + segOffset` for both re-encoded and packet-copied portions (using seg.in as reference so the join is seamless).
- Audio is always lossless packet-copy regardless of frameAccurate.

**State changes:**
- Replaced `inPoint`/`outPoint` scalars with `segments: Segment[]` and `activeSegIdx: number`.
- Added `frameAccurate: boolean` checkbox (default off).
- Added `thumbnails: WrappedCanvas[]` (fetched once per blob load).
- `activeSeg = segments[activeSegIdx]`; `inPoint/outPoint` derived from it.
- `totalKeptDuration = sum(seg.out - seg.in)` replaces `trimmedDuration`.

**Thumbnail filmstrip:**
- In the blob effect: after building the Input, calls `input.getDurationFromMetadata()` (falling back to `track.getDurationFromMetadata()`), computes 12 evenly-spaced timestamps, uses `CanvasSink(track, { width: 160 }).canvasesAtTimestamps(timestamps)` to decode them, stores non-null results in `thumbnails` state.
- Rendered below the slider as `ThumbnailCanvas` components (copy WrappedCanvas → DOM canvas via `getContext('2d').drawImage`; clicking seeks the preview to `wc.timestamp`).

**"Cut" button:**
- `handleCutSelection`: removes the range `[inPoint, outPoint]` from the active segment, splitting it into up to two replacement segments (`{ in: seg.in, out: inPoint }` + `{ in: outPoint, out: seg.out }`), filtered at 100ms minimum duration. Updates `segments` and resets slider to first replacement.

**Multi-segment UI:**
- Segment bands: non-active segments rendered as `bg-primary/40` absolute divs overlaid on the slider track; clicking a band sets `activeSegIdx`.
- Segment chips: when `segments.length > 1`, shows labeled chips (In–Out times) with × remove buttons.
- "Cut" button visible in footer alongside the existing "Preview" button.
- "Frame-accurate" HTML checkbox (default off) in the footer.

**handleValueChange/handleValueCommit:**
- Both updated to mutate `segments[activeSegIdx]` only (not a scalar).

**Verified:**

- `npx vite build` → main chunk 460 kB (up 4 kB), mediabunny lazy chunk 641 kB (unchanged) ✓

## Session 5 — Native system-audio capture (P1)

Implemented `native-system-audio-capture.md` plan against the `main` post-trim-editor-v2 state.

**Backend (`src-tauri/src/`):**

- **`system_audio_stream.rs`** — new module. `SystemAudioStreamState { streams: Mutex<HashMap<u32, SysAudioHandle>> }`.
  - `start_system_audio_stream(section_index, sample_rate, channels, on_chunk, state)`: creates `SystemAudioCapture`, takes its receiver, calls `start()`, spawns a worker that drains `AudioChunk`s, builds a 16-byte LE header (`u32 sample_rate | u16 channels | u16 reserved | u64 timestamp_ms`) + interleaved f32 PCM payload, and sends via `Channel<InvokeResponseBody>::send(Raw(...))`. Ack-based backpressure via `Condvar` credit (`MAX_INFLIGHT = 8`). Worker joins on stop; logs sent/dropped counts.
  - `stop_system_audio_stream(section_index, state)`: removes handle, joins worker.
  - `ack_system_audio_chunk(section_index, state)`: credit++ / notify_one.
  - Wire format: 16-byte header aligned so PCM payload starts at byte 16 → zero-copy `Float32Array(buf, 16)` view on JS side.
- **`lib.rs`** — added `mod system_audio_stream;`, `use system_audio_stream::SystemAudioStreamState;`, `.manage(system_audio_stream_state)`, and three commands registered in `generate_handler!`.

**Frontend (`frontend/src/`):**

- **`lib/native-system-audio.ts`** — new module, mirrors `native-screen.ts`.
  - `buildAudioSource(audioCtx, numChannels, destination)`: tries `AudioWorkletNode` (inline `RingBufferSourceProcessor` registered via Blob URL); falls back to `ScriptProcessorNode` ring-buffer if `audioWorklet` unavailable (WKWebView compat). Both connect to `destination` (mix, for recording) AND via `silentGain (gain=0)` to `audioCtx.destination` (keeps graph rendering without speaker playback).
  - `startNativeSystemAudioStream(sectionIndex, audioCtx, destination, opts)`: sets up source node, registers `channel.onmessage` to parse header / de-interleave f32 PCM into per-channel `Float32Array[]` / push to ring buffer / ack. Invokes `start_system_audio_stream`.
  - `stopNativeSystemAudioStream(sectionIndex)`: disconnects audio nodes, invokes `stop_system_audio_stream`.
- **`components/asmr-recorder/recording-canvas.tsx`**:
  - Added `import { startNativeSystemAudioStream, stopNativeSystemAudioStream }` from `native-system-audio.ts`.
  - Added `nativeSystemAudioCleanupRef` ref.
  - `acquireAudioTrack`: when `wantSystemAudio && !hasMediaApi("getDisplayMedia")` sets `wantNativeSystemAudio = true` (instead of just warning); forces `needsMixContext = true`; after building `AudioContext + destination`, calls `startNativeSystemAudioStream` connected to `destination`; stores `stopNativeSystemAudioStream` in cleanup ref.
  - Cleanup handler: calls `nativeSystemAudioCleanupRef.current?.()` before AudioContext closes.

  `startExternalRecording` (`recording-context.tsx:199`, flips state only, no backend invoke)

  `startRecording`) are never mounted (`App.tsx` mounts only `ASMRRecorder`). Confirmed by
  grepping every `generate_handler!` command against the frontend.
- **System audio is broken in the real app.** `acquireAudioTrack` (`recording-canvas.tsx:505`)
  uses `getDisplayMedia({audio:true})`, blocked in WKWebView. The SCK audio capturer
  (`system_audio_macos.rs`) is complete but only wired to the dead manager.
- **Dead deps:** `cpal`, `nokhwa`, `ffmpeg-next` are only used by the dead path. `image` and
  `screencapturekit` must stay (live screen + SCK audio).
