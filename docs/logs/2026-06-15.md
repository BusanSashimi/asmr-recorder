## Per-section transport teardown — `Channel.onmessage` neuter on stop (commit `18ff0e0`)

**Plan:** `ai-dev/doc/per-section-transport-unregister.md`

- Added module-level `channels = new Map<number, Channel<ArrayBuffer>>()`.
- `startNativeScreenStream`: `channels.set(sectionIndex, channel)` before invoke.
- `stopNativeScreenStream`: looks up the channel, sets `channel.onmessage = () => {}`, deletes the entry, then invokes the backend stop. Previous stop was backend-only.

- Added module-level `streamChannels` map (renamed from `channels` to avoid shadowing the `channels: number` param destructured from `opts` inside `startNativeSystemAudioStream`).
- `startNativeSystemAudioStream`: `streamChannels.set(sectionIndex, channel)` before invoke.
- `stopNativeSystemAudioStream`: neuters and deletes the channel first, then runs the existing `disconnect()` + `cleanups.delete` + backend stop.
