## Trim modal overflow fix

Recording confirmed working in the live dev server. Trim editor modal had two layout bugs:

1. **Filmstrip thumbnails overflowed** (`b0f19eb`): `ThumbnailCanvas` had `flex-1` but no
   `min-w-0`, so 10× 160px canvases expanded past the modal boundary. Fixed: added `min-w-0`,
   removed the no-op `object-cover` (canvas ignores it).

2. **Full content overflow** (`c6710ec`): `DialogContent` uses CSS Grid; grid items default to
   `min-width: auto`, so the slider and filmstrip expanded the grid beyond `max-w-2xl`. Fixed:
   added `overflow-hidden` to `DialogContent` and `min-w-0` to the controls wrapper div.
   Confirmed fixed in the dev server.
